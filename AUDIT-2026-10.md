# Security Audit — SIP-01/indexstr-v3 — 2026-10-20

## Summary

Indexer network node for SIP-01: React SPA crawler dashboard + `scrapling-node/` Python headless node (source tag `indexstr/v3`). Key hygiene is strong: `SIP01_NSEC` is env-only (config loader refuses file-based keys), generated key files are chmod 0600 and never logged; relay fan-out is a curated allowlist; SSRF guard with DNS-resolution checks ships in the node. **Intake caveat (audit focus):** the indexer-mode "intake" flag is *reserved but not implemented* — the node currently only crawls/publishes its own signed observations; it does not yet accept third-party kind 39697 events. When intake lands, `sip01.py:validate_event()` (schema + d↔u + x↔content) must be paired with the existing `nostr.py:verify_event()` signature check — today `validate_event` alone does NOT verify the Nostr signature.
